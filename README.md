# SLZ Digital Launchpad

Create a complete, premium, dark-themed marketing agency 
website for SLZ Digital, a Brazilian digital marketing 
agency. The website must be fully in Brazilian Portuguese.

## BRAND IDENTITY
- Primary color: #00AEEF (cyan blue)
- Accent: #C0C0C0 (silver) for subtle details
- Background: #080808 (near black)
- Surface: #111111 and #161616 for cards
- Text: #FFFFFF primary, #888888 secondary
- Highlight color for keywords: #00AEEF
- Fonts: Space Grotesk (headings), 
  Syne (body) — import from Google Fonts
- Style: tech, premium, dark, clean
- NO purple, no orange gradients
- NO Gilroy, NO Montserrat
